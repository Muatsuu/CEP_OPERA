# CEP_OPERA
Uma extensão para navegador que preenche automaticamente os campos relacionados ao CEP digitado pelo usuario no sistema OPERA HOSPITALITY de Hotelaria.
Ele usa duas APIS (VIACEP e BRASILAPI) para consulta, se uma não funcionar a outra estará disponivel.
Adionado recentemente as funções de verificação de usuario permitido e preenchimento automatico de PIN do billing.

Não há mais necessidade de acessar o arquivo de traduções para carregar e ler o que estiver escrito na tela, adicionei funções locais para fazer isso sem a necessidade de fazer um Fetch no raw do Gihub, pois a rede interna na Accor bloqueou o acesso.
